App Repair & Upgrade Bot

Automated health checks and repair triage for Money Hunter AI.

What it does

  • Runs on a six-hour schedule, on app-code changes, and manually from GitHub Actions.
  • Checks required app files, JSON validity, Python syntax, JavaScript syntax when Node is available, HTML parsing warnings, and common accidentally committed secret patterns.
  • Publishes a timestamped diagnostic report.
  • Creates or updates a GitHub repair issue when checks fail, with the run link and safe repair instructions.

Repair policy

It diagnoses and reports automatically. It does not overwrite production code or merge unreviewed changes. A future AI coding agent can prepare tested pull requests, but actual AI code generation requires an authorized model/service; this free version does not pretend to have that capability.

It never reads private claimant data, files claims, signs declarations, changes payments, or spends money.
