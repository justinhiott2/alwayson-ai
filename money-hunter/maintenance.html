Automated maintenance

Money Hunter runs scheduled diagnostics without an external AI API key. It checks required app files, JSON validity, Python and JavaScript syntax, HTML parsing warnings, and common accidentally committed secret patterns.

When checks fail, the workflow creates or updates a GitHub issue with the diagnostic report and run details. Routine checks do not require Gemini, Google AI Studio, or a paid AI service.

For complex code changes, review the issue and make a tested change through GitHub. The maintenance workflow does not automatically merge or deploy unreviewed code.

Repair policy

Diagnostics run automatically. AI code changes are limited to app/test files, checked before a draft pull request, and never deployed without review. Sensitive workflows, generated reports, claimant data, claim submission, legal declarations, authentication, and payment behavior are protected from the coding agent.

It never reads private claimant records, files claims, signs declarations, changes payments, or spends money.
