AI code repair agent

The coding workflow can inspect a repair issue, ask GitHub Models to draft a small patch, run checks, and open a draft pull request. It never merges or deploys automatically.

  1. Open GitHub token settings and create a token that has the models:read permission for GitHub Models.
  2. Open this repository's Actions secrets.
  3. Create a repository secret named GH_MODELS_TOKEN and paste the token value. Never put the token in a code file or issue.
  4. Open AI Code Repair Agent. Run it manually with a GitHub issue number, or create a repair issue titled [AI repair] ....
  5. Review the draft pull request and test the app before merging.

GitHub Models access and usage limits depend on GitHub's current account and service policy. No paid API key is included or assumed. I cannot create this private token or repository secret on your behalf.

Repair policy

Diagnostics run automatically. AI code changes are limited to app/test files, checked before a draft pull request, and never deployed without review. Sensitive workflows, generated reports, claimant data, claim submission, legal declarations, authentication, and payment behavior are protected from the coding agent.

It never reads private claimant records, files claims, signs declarations, changes payments, or spends money.
